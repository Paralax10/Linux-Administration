Week 3 - Linux Server Monitoring

Linux Commands

date: Displays the current date, time and timezone.

date '+%Y-%m-%d %H:%M:%S %Z (%z)'

uptime: Displays how long the server has been running.

uptime -p

df: Displays filesystem disk usage.

df -h /

free: Displays total and available memory.

free -h

Piping example: This command extracts the root filesystem's disk usage percentage.

df -P / | awk 'NR==2 {print $5}'

The pipe sends the output of df to awk, which extracts the fifth column.

How the Bash Script Works

The Bash script collects system information using Linux commands and command substitution. The results are stored in variables and then inserted into an HTML document.

The script defines a function called get_disk_status, which checks the root filesystem's disk usage percentage.

If disk usage is below 80%, the status is OK. If usage is 80% or higher, the status is WARNING.

The generated HTML report is saved to /var/www/html/viikko3/index.html.

Automatic Updates

The report is automatically regenerated once every minute using cron.

* * * * * /bin/bash /opt/viikko2/week3/report.sh >> /tmp/viikko3-cron.log 2>&1

Cron runs the script using Bash. The generated report replaces the previous report, so the website always displays the latest collected information.

The cron service is enabled to start automatically when the virtual machine reboots.

What I Learned

One issue I encountered was that the script produced errors when executed through cron because it was being interpreted using the wrong shell. I solved this by explicitly specifying Bash in the cron command.

This helped me understand why specifying the correct interpreter is important when running scripts automatically.
